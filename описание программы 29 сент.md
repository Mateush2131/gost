## 1. Общие сведения

1.1. Обозначение и наименование программы:  
**AlaCode** — веб-приложение портфолио Python-разработчика.

1.2. Программное обеспечение, необходимое для функционирования:  
- Node.js 18 или выше  
- npm / yarn  
- PostgreSQL (через Supabase или локально)  
- Современный веб-браузер

1.3. Языки программирования:  
TypeScript, JavaScript (React/Next.js), SQL (Prisma).

---

## 2. Функциональное назначение

Программа предназначена для:
- публикации портфолио проектов и навыков разработчика;
- приёма заявок на услуги (Telegram-боты, backend, API);
- администрирования поступивших заявок.

Классы решаемых задач: информационная система презентационного и CRM-типа (лёгкий приём заявок).

Ограничения: требует постоянного подключения к базе данных и сети Интернет.

---

## 3. Описание логической структуры

### 3.1. Основные компоненты

| Компонент | Назначение |
|-----------|------------|
| `app/page.tsx` | Главная страница, загрузка проектов |
| `app/layout.tsx` | Корневой layout, метаданные |
| `app/admin/` | Административная панель |
| `app/api/` | API-маршруты (заявки и др.) |
| `components/` | UI-компоненты портфолио |
| `lib/` | Вспомогательные функции (проекты, БД) |
| `prisma/schema.prisma` | Модель данных |
| `middleware.ts` | Защита маршрутов `/admin` (Basic Auth) |

### 3.2. Алгоритм работы

1. Пользователь открывает сайт → отображается портфолио.  
2. Пользователь заполняет форму заявки → данные отправляются на сервер → сохраняются в таблицу `Order`.  
3. Администратор переходит на `/admin` → проходит Basic Auth → видит список заявок и может менять статусы.

### 3.3. Связи

- Frontend (Next.js App Router) ↔ Backend API Routes  
- Prisma Client ↔ PostgreSQL (Supabase)  
- Middleware перехватывает запросы к `/admin`

## 4. Используемые технические средства

## 5. Вызов и загрузка

### 5.1. Способ вызова программы

**Вариант 1 — локальный запуск (разработка):**
```bash
npm install
npx prisma generate
npx prisma db push   # или migrate
npm run dev
```
Программа доступна по адресу: `http://localhost:3000`

**Вариант 2 — production:**
```bash
npm run build
npm run start
```
Или деплой на платформу (Vercel / Railway) с указанием переменных окружения.

### 5.2. Входные точки

| Точка входа | Описание |
|-------------|----------|
| `/` | Главная страница портфолио |
| `/admin` | Административная панель (защищена) |
| API routes (`/api/...`) | Обработка заявок и данных |

### 5.3. Дополнительные сведения

- Объём исходного кода: небольшой (десятки файлов).  
- Использование оперативной памяти: типичное для Next.js (зависит от трафика).  
- Конфигурация: файл `.env` (см. `.env.example`).

Обязательные переменные окружения:
```
DATABASE_URL=...
ADMIN_USER=admin
ADMIN_PASS=...
NEXT_PUBLIC_SUPABASE_URL=...
NEXT_PUBLIC_SUPABASE_ANON_KEY=...
```

## 6. Входные данные

| Данные | Источник | Формат |
|--------|----------|--------|
| Заявка | Форма на сайте | name, email, phone, service, message (строки) |
| Учётные данные админа | HTTP Basic Auth | login:password |
| Список проектов | `lib/projects` / БД | объекты проектов |

Предварительная подготовка: настройка `.env`, применение миграций Prisma.

| Запись в БД | Таблица `Order` | PostgreSQL row |
