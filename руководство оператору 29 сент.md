## 1. Назначение программы

Веб-приложение «AlaCode» предназначено для:
- просмотра портфолио Python-разработчика;
- отправки заявки на услуги (Telegram-боты, backend, API);
- (для администратора) просмотра и управления заявками.

Программа работает в браузере. Специальных знаний программирования от обычного пользователя не требуется.

---

## 2. Условия выполнения программы

### 2.1. Для посетителя сайта (оператор-клиент)
- Компьютер, планшет или смартфон  
- Современный браузер (Chrome, Firefox, Safari, Edge)  
- Доступ в Интернет  

### 2.2. Для администратора
- Всё вышеперечисленное +  
- Знание логина и пароля администратора  
- Доступ к адресу сайта с путём `/admin`

### 2.3. Минимальные программные средства
- Node.js 18+ (на сервере)  
- Работающая база данных PostgreSQL (Supabase)

## 3. Выполнение программы (загрузка, запуск, работа, завершение)

### 3.1. Загрузка и запуск (для администратора / разработчика)

**Локальный запуск:**
1. Открыть терминал в папке проекта.  
2. Выполнить:
   ```bash
   npm install
   npx prisma generate
   npx prisma db push
   npm run dev
   ```
3. Открыть браузер и перейти по адресу `http://localhost:3000`.

**Production-запуск:**
```bash
npm run build
npm run start
```
Или использовать кнопку деплоя на выбранной платформе.

**Признак успешного запуска:** в терминале появляется сообщение о том, что сервер слушает порт 3000 (или другой), главная страница открывается без ошибок.

### 3.2. Работа обычного пользователя (посетителя)

1. Открыть сайт в браузере.  
2. Просмотреть портфолио, проекты, навыки.  
3. Для отправки заявки:
   - заполнить поля формы (имя, email, телефон, услуга, сообщение);
   - нажать кнопку отправки;
   - дождаться сообщения об успешной отправке.

### 3.3. Работа администратора

1. Перейти по адресу `https://ваш-сайт/admin` (или `http://localhost:3000/admin`).  
2. Ввести логин и пароль (Basic Auth).  
3. После успешного входа открывается панель со списком заявок.  
4. Можно просматривать заявки и менять их статус.  
5. Для выхода — закрыть вкладку или очистить данные аутентификации браузера.

### 3.4. Завершение работы

- Пользователь: просто закрыть вкладку браузера.  
- Администратор: то же самое.  
- Сервер (разработчик): в терминале нажать `Ctrl+C`.

## 4. Сообщения оператору (включая аварийные ситуации)

| Сообщение / ситуация | Содержание | Действия оператора |
|----------------------|------------|--------------------|
| Форма успешно отправлена | «Заявка принята» / успешный экран | Ничего, можно закрыть страницу |
| Ошибка отправки формы | Не удалось сохранить / сеть | Проверить интернет, заполнить поля заново, повторить отправку |
| 401 Unauthorized на /admin | Требуется логин и пароль | Ввести правильные учётные данные. Если забыли — обратиться к владельцу сайта |
| Ошибка подключения к БД | Страница не загружается / ошибка сервера | Сообщить администратору. Проверить, что DATABASE_URL корректный и Supabase доступен |
| 500 Internal Server Error | Внутренняя ошибка сервера | Обновить страницу. Если повторяется — сообщить разработчику, приложить скриншот |
| Страница не найдена (404) | Неверный адрес | Проверить URL. Для админки использовать именно `/admin` |
| Сайт не открывается | Таймаут / нет соединения | Проверить интернет, статус хостинга, DNS |

### 4.1. Действия при сбое

1. Обновить страницу (F5).  
2. Очистить кэш браузера / открыть в режиме инкогнито.  
3. Проверить интернет-соединение.  
4. Если проблема на стороне сервера — дождаться восстановления или обратиться к администратору хостинга.  
5. **Повторный запуск** (для разработчика): остановить процесс (`Ctrl+C`) и снова выполнить `npm run dev` / `npm run start`.

### 4.2. Возможность повторного запуска

После устранения причины сбоя (сеть, БД, переменные окружения) повторный запуск программы допускается без переустановки. Достаточно перезапустить сервер Node.js.
